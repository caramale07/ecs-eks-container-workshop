# ECS and EKS container delivery workshop

This starter project supports a hands-on workshop deploying one small web application to Amazon ECS and Amazon EKS. You will work in Visual Studio Code, create a GitHub repository, make a local enhancement, and use Jenkins to build and deploy the application.

Follow the separate Word workshop guide provided by your instructor for concepts, prerequisites, AWS setup, the numbered steps, and expected results.

To run a named VS Code task, choose **Terminal** from the top menu bar, choose **Run Task…**, and select the task. On macOS, Terminal is beside Run; choose Terminal. The circular arrow on a task terminal reruns the current task.

Start with **0 Prepare workstation tools**. It checks Python, Git, AWS CLI, the Session Manager plugin, and kubectl. On macOS, it downloads the official Session Manager plugin into the ignored `.lab/` folder if it is missing. The task does not sign in to AWS Academy or create AWS resources; use the separate guide for AWS sign-in and credentials. Windows and Linux users can install the plugin using the AWS links in the guide.
